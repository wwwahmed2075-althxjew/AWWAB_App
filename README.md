# أوّاب | AWWAB — Black Edition

تطبيق أوّاب الإسلامي — واجهة ويب تقدمية (PWA) بهوية iOS Glass أحادية اللون بالأسود والأبيض.

## حالة التنفيذ الحالية
- تم اعتماد نظام مظهر داكن/فاتح/تلقائي بالأسود والأبيض والرمادي فقط.
- تم تحديث طبقات الزجاج والـ Dock وشريط الحالة لملاءمة تجربة iPhone على الويب.
- المشروع الحالي PWA؛ لا يُعد تطبيق iOS أو Android أصليًا بعد.
- الميزات المتقدمة (التلاوة الذكية، المزامنة السحابية، القبلة، خطط الختمة الكاملة والإشعارات الأصلية) تُنفّذ وتُختبر على مراحل منفصلة.

## الملفات
- `index.html`: هيكل التطبيق والصفحات.
- `style.css`: الهوية البصرية الداكنة.
- `app.js`: التفاعلات والتخزين المحلي والاتصال بالخدمات.
- `manifest.webmanifest` و`sw.js`: إعدادات PWA والعمل دون اتصال جزئي.
- `icon.svg`: أيقونة أوّاب.

## النشر التجريبي على GitHub Pages
ارفع محتويات المجلد إلى جذر مستودع GitHub، مع استبدال الملفات القديمة، ثم فعّل Pages من فرع `main` ومجلد `/root`.

## ملاحظات قبل النشر الرسمي
هذه نسخة تأسيسية متقدمة وليست إصدارًا نهائيًا موثقًا للنشر على المتاجر. يلزم:
1. مراجعة نصوص الأذكار وتوثيق مصادرها.
2. اختبار مواقيت الصلاة على المدن وطرق الحساب المعتمدة محليًا.
3. إضافة سياسة خصوصية وشروط استخدام وبيانات المطور.
4. اختبار قارئ القرآن والاتصال ومصادر البيانات.
5. بناء تطبيق Android/iOS أصلي أو تغليف PWA وفق متطلبات المتاجر.
