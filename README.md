# ملاذ | MILADH

تطبيق إسلامي عربي مبني باستخدام Flutter، يضم القرآن الكريم والأذكار والصلاة والتذكيرات اليومية.

## الهوية والتصميم
- الاسم الظاهر: ملاذ.
- واجهة عربية RTL.
- تصميم زجاجي هادئ بعناصر صغيرة ومريحة.
- أوضاع المظهر: فاتح، داكن، وتلقائي حسب إعدادات الجهاز.

## المزايا الموجودة في الفرع الحالي
- فهرس سور القرآن والقراءة وحفظ آخر موضع قراءة.
- حفظ الآيات في المفضلة بالضغط المطوّل داخل قارئ النص.
- مصحف المدينة النبوية، مع تنزيل الصفحات للعمل دون اتصال والتحقق من ملفاتها.
- الأذكار والأقسام والعدادات.
- سبحة إلكترونية بعدادات مستقلة محفوظة لكل ذكر.
- مواقيت الصلاة والقبلة والتنبيهات.
- تذكيرات قابلة للتفعيل والتخصيص، ومنها تذكير آية الكرسي بعد الصلاة.
- المناسبات الهجرية مع عرض التاريخ المتوقع والتنبيه إلى احتمال اختلاف الرؤية.
- مشاركة التطبيق، الإبلاغ عن خلل، وصفحة نبذة وسجل الإصدارات.

## ملاحظات قبل الإصدار النهائي
- أيقونة التطبيق النهائية ستُضاف من الصورة التي يرسلها صاحب المشروع.
- مكتبة التلاوات والتنزيل دون إنترنت لم تُفعّل بعد؛ يجب التأكد من حقوق كل تسجيل وشروط إعادة توزيعه قبل تضمينه.
- يجب إتمام اختبار APK على جهاز Android فعلي.
- بناء GitHub Actions الحالي ينتج ملف APK للتثبيت والاختبار، ولا يعني وحده اعتماد إصدار متجر أو توقيعه بمفتاح نشر خاص.

## البناء
يتم البناء عبر GitHub Actions على الفرع `feature/awwab-eleven-updates`. لا تُعد النسخة إصدارًا نهائيًا قبل اكتمال التحليل والبناء والاختبار، وإضافة أيقونة ملاذ النهائية.
