# مشكاة | Mishkat

تطبيق إسلامي عربي لنظام Android، مبني باستخدام Flutter وDart.

## الهوية المعتمدة
- الاسم المعروض: **مشكاة** بالعربية.
- الأيقونة الخارجية المعتمدة: صورة المسجد والهلال الذهبية التي قدمها المستخدم (يجب وضع الملف الأصلي في `assets/branding/mishkat_icon.jpg` قبل اعتماد APK النهائي).
- الواجهة الداخلية: كحلي داكن، بطاقات زجاجية، حدود وإضاءات شامبين ذهبية، وأيقونات ذهبية؛ تطبق على كل الشاشات.
- RTL وعناصر صغيرة ومريحة، وخمسة أقسام رئيسية.

## نطاق الميزات المطلوبة
- القرآن الكريم: فهرس 114 سورة، البحث، نص حفص، مصحف المدينة 604 صفحة، حفظ الموضع والمفضلة والنسخ والمشاركة والورد والختمة والعمل دون اتصال بعد التنزيل.
- الصلاة: مواقيت محسوبة حسب الموقع وطريقة الحساب والمذهب، عد تنازلي، القبلة، وأذان اختياري.
- الأذكار: الصباح والمساء والنوم والاستيقاظ وما بعد الصلاة والرقية، العدادات والمفضلة والأذكار المخصصة، مع مراجعة النصوص والمصادر.
- التنبيهات: مواقيت الصلاة، أذكار دورية قابلة للتخصيص، الصلاة على النبي ﷺ، وآية الكرسي بعد الصلاة.
- المسبحة والختمة والورد اليومي والإعدادات وحفظ البيانات محليًا.

## الحالة الفنية
هذا المستودع ما زال مشروع Flutter قيد التطوير. توجد وظائف أولية للقرآن ومصحف المدينة والمواقيت والقبلة والأذكار والمسبحة والختمة، لكن بعض الميزات المذكورة أعلاه تحتاج استكمالًا واختبارًا. لا تعتبر العناصر المرئية أو بناء APK دليلًا على اكتمال الوظائف.

## البناء والاختبار
يشغّل GitHub Actions فحوص Flutter ويبني APK ARM64. يجب مراجعة سجل البناء والاختبارات لكل نسخة. اختبار GPS والبوصلة والتنبيهات الفعلية يحتاج جهاز Android حقيقي.

## مبادئ التنفيذ
- لا تحذف ميزة معتمدة.
- لا تعرض مواقيت أو بيانات دينية تجريبية كأنها حقيقية.
- لا تستخدم نصوص قرآن أو أحاديث أو أذكار غير موثقة.
- احفظ البيانات محليًا واعمل دون اتصال حيثما أمكن.
- لا تعلن اكتمال ميزة أو اختبار قبل التحقق الفعلي.
