# ملاذ

تطبيق إسلامي عربي يعمل على Android باستخدام Flutter وDart.

## الهوية والاتجاه
- الاسم المعروض للمستخدم: **ملاذ** بالعربية فقط.
- Android أولًا، مع قابلية بناء نسخة iOS لاحقًا.
- أدوات تطوير مجانية، دون اشتراكات أو خدمات مدفوعة.
- واجهة عربية RTL، زجاجية داكنة بعناصر صغيرة وأنيقة.
- شريط تنقل سفلي بخمسة أقسام: الرئيسية، القرآن، الأذكار، الصلاة، المزيد.

## الأقسام المستهدفة
1. الرئيسية والورد اليومي.
2. القرآن الكريم: فهرس السور، البحث، المصحف العثماني، التلاوة، حفظ الموضع، الحفظ والمراجعة والعمل دون اتصال.
3. الأذكار: الصباح والمساء والنوم والاستيقاظ والرقية وأذكار ما بعد الصلاة مع العدّ والتقدم.
4. الصلاة: مواقيت حسب الموقع وطريقة الحساب، الأذان والتنبيهات والقبلة.
5. المزيد: السبحة والختمة والإعدادات والخطوط والمظهر.

## الحالة الحالية — ليست إصدارًا نهائيًا
المستودع يحتوي على هيكل Flutter أولي ونسخة ويب أقدم. شاشة القرآن تتضمن فهرسًا وتنزيلًا لنص السور مع تحقق من عدد الآيات، كما يتضمن قارئ مصحف المدينة آلية تحقق SHA-1 لصفحات SVG الـ604 عند تنزيلها. هذا التحقق البرمجي لا يغني عن مراجعة المصدر القرآني ومطابقة الصفحات بصريًا.

لا تزال وظائف مواقيت الصلاة الحقيقية والأذان والقبلة والإشعارات المجدولة وبعض وظائف الأذكار والختمة والإعدادات بحاجة إلى تنفيذ واختبار. لا تُعرض بيانات شكلية على أنها مواقيت أو نتائج حقيقية.

## البناء والاختبار
GitHub Actions يشغّل فحوص Flutter ثم يبني APK إصدارًا مقسمًا حسب معمارية الجهاز لتقليل حجم التنزيل. ملفات APK الناتجة تجريبية إلى أن يتم اختبارها على أجهزة Android فعلية؛ لا يوجد ادعاء باكتمال التطبيق أو توقيعه للنشر.

## مبادئ العمل
- لا تُحذف ميزة معتمدة دون موافقة المستخدم.
- حفظ البيانات محليًا والعمل دون اتصال حيثما أمكن.
- توثيق مصادر القرآن والأذكار والتحقق منها.
- اختبار الوظائف على جهاز Android فعلي قبل إعلان اكتمالها.
