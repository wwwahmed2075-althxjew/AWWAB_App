# أوّاب | AWWAB

بدأت إعادة بناء أوّاب كتطبيق Flutter أصلي باستخدام Dart، بدل الاكتفاء بتغليف نسخة الويب القديمة.

## الاتجاه المعتمد
- Android أولًا، مع قابلية بناء نسخة iOS لاحقًا.
- Flutter + Dart.
- أدوات وخدمات تطوير مجانية قدر الإمكان، دون اشتراكات مدفوعة.
- واجهة عربية RTL بهوية أحادية اللون: الأسود والأبيض والدرجات الرمادية.
- Glassmorphism حقيقي: شفافية وBlur وحدود دقيقة وطبقات عائمة.
- Dock سفلي عائم وثابت بخمسة أقسام: الرئيسية، القرآن، الأذكار، الصلاة، المزيد.
- عناصر وأزرار صغيرة وأنيقة واستجابة وانتقالات سلسة.

## أقسام التطبيق المستهدف
1. الرئيسية والورد اليومي.
2. القرآن الكريم: فهرس السور، البحث، عرض المصحف بالرسم العثماني، التلاوة والتحكم، حفظ موضع القراءة، الحفظ والمراجعة.
3. الأذكار: الصباح والمساء والنوم والاستيقاظ والرقية وأذكار ما بعد الصلاة، مع العدّ والتقدم.
4. الصلاة: مواقيت دقيقة وفق الموقع وطريقة الحساب، الأذان والتنبيهات والقبلة.
5. المزيد: السبحة، الختمة، الإعدادات، اللغات والخطوط والمظهر.

## الحالة الحالية
هذه بداية الهيكل الأصلي الجديد وليست إصدارًا نهائيًا. تم تأسيس واجهة Flutter الأساسية وDock الزجاجي، وواجهات أولية للأقسام، وسبحة تحفظ العدّ محليًا. ما زالت وظائف المصحف والتلاوة والبيانات الدقيقة للصلاة والأذان والختمة والإعدادات الكاملة قيد التنفيذ والاختبار؛ لا تُعرض بيانات تجريبية على أنها بيانات حقيقية.

## البناء
GitHub Actions يبني APK تجريبيًا عند تحديث ملفات Flutter أو تشغيل Workflow يدويًا. ملف Debug APK للاختبار فقط وليس إصدار متجر موقّعًا.

## مبادئ التنفيذ
- لا تُحذف ميزة معتمدة دون الرجوع للمستخدم.
- حفظ البيانات محليًا والعمل دون اتصال حيثما أمكن.
- توثيق مصادر القرآن والأذكار واختبارها قبل الاعتماد.
- اختبار الوظائف على جهاز Android فعلي قبل إعلان اكتمالها.
